# Resume Builder

Craft clean, professional, ATS-friendly resumes with a live editing experience and instant PDF export.

## ✨ Features

- Real-time resume preview
- Unlimited Experience, Projects, Skills & Certifications
- Clean, minimal, recruiter-friendly design
- Print-perfect A4 layout
- Clickable links preserved in PDFs
- Dynamic sections with zero formatting effort
- Built using pure HTML, CSS & JavaScript

## ⚡ Why This Project?

Most resume builders are bloated, restrictive, or paid.

This one is built for:
- Speed
- Simplicity
- Flexibility
- Professional output

No clutter. No templates overload. Just a focused resume-building experience.
