
Resume Builder — polished, flexible, fast

Create a professional, print-ready resume from a guided form — instantly.

Highlights

- Live, WYSIWYG preview: edit fields on the left and watch the resume update on the right in real time.
- Truly repeatable sections: add or remove any number of Experience, Projects, Skills, and Certifications entries without limits.
- Structured bullets and multiline fields for responsibilities, achievements, and project details — enter lists with newlines or commas.
- Clickable links preserved in PDF: GitHub and live-demo URLs remain active when exported.
- Print-optimized output: a clean, two-column A4 resume view with the editor hidden when printing or saving to PDF.
- Safe URL handling and normalization to avoid broken links and ensure correct targets.
- Blank-by-default starter state — no preset data; build your resume from scratch.

Why it's different

- Designed for speed: focused form inputs that map directly to resume sections, reducing formatting effort.
- Flexible data model: sections are arrays under the hood, enabling programmatic export, templating, or integration with other tools.
- Minimal, print-first styling: the preview is the final product — what you see is what prints.

Quick usage

1. Open `index.html` in your browser.
2. Fill personal details, add experience/projects/skills/certifications as needed.
3. Use the "Print / Save PDF" button to export a print-optimized resume (links preserved).

Extensibility

- Swap or extend styles in `styles.css` to apply different visual themes or templates.
- The app is plain HTML/CSS/JS — easily integrated into a static site or a small server if you want persistence or PDF automation.
